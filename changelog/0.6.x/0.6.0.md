# 0.6.0 — 2026-11-13

## Added

- **`scorecard_search_schools`** filters by maximum net price, minimum completion rate, HBCU status, and locale before pagination. ([#55](https://github.com/cyanheads/college-scorecard-mcp-server/issues/55))
- **School profiles and value analysis** return two- and four-year undergraduate federal Direct Loan borrower statuses with OPEID6 scope, cohort counts, and the published decimals or bins. ([#58](https://github.com/cyanheads/college-scorecard-mcp-server/issues/58))

## Changed

- Remove inherited titles from concrete school and program resource entries; template titles remain.
- **Runtime** requires Bun 1.4.4 or later when running on Bun.

## Fixed

- **Three-year declining-balance repayment** carries its discontinued status and 2016–17 file vintage in school profiles, value analysis, and comparisons. ([#51](https://github.com/cyanheads/college-scorecard-mcp-server/issues/51))
- **Program tools and comparison prompt** lead with completion-based earnings and distinguish the legacy highest-credential series. Program tools render all results as readable text with availability, provenance, and continuation. ([#52](https://github.com/cyanheads/college-scorecard-mcp-server/issues/52))
- **`scorecard_list_fields`** reports observed API sort support and includes pooled full-time retention for four-year and less-than-four-year institutions. ([#53](https://github.com/cyanheads/college-scorecard-mcp-server/issues/53))
- **Operating certification** appears where reported in school tools and resources, with an explicit certification filter in school search. ([#54](https://github.com/cyanheads/college-scorecard-mcp-server/issues/54))
- **`scorecard_compare_schools`** leaves descriptive metrics and single-school results unranked and preserves unranked rows in the comparison prompt. ([#56](https://github.com/cyanheads/college-scorecard-mcp-server/issues/56))
- **Input normalization** clamps negative dollar inputs to zero with a notice, deduplicates earnings vintages in caller order, and maps six-digit CIP queries to their four-digit group. Exhausted CIP pages explain how to restart. ([#57](https://github.com/cyanheads/college-scorecard-mcp-server/issues/57))
- **Readable output** preserves reported numeric precision for comparison values, historical repayment, and family income. Upstream HTTP error bodies stay server-side by default.
- **MCPB packaging** retains runtime files when stripping dependency development files.
