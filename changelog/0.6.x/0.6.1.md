# 0.6.1 — 2026-11-27

## Added

- **National program earnings** report one- and four-year medians, 25th and 75th percentiles, and counts by CIP and credential across both program tools and resource routes. Each statistic carries its own availability and provenance. ([#63](https://github.com/cyanheads/college-scorecard-mcp-server/issues/63))
- **Graduate debt** exposes `median_debt_at_institution` for credentials 5–8 with its own dictionary provenance. ([#61](https://github.com/cyanheads/college-scorecard-mcp-server/issues/61))
- **Program search** accepts ZIP and optional radius in miles or kilometers and applies both before school pagination. ([#64](https://github.com/cyanheads/college-scorecard-mcp-server/issues/64))

## Changed

- **Framework tooling** updates development and packaging checks and excludes Vitest caches from the MCPB bundle.

## Fixed

- **Zero range bounds** send `0.0` when zero is an upper endpoint and echo numeric zero to the caller. ([#60](https://github.com/cyanheads/college-scorecard-mcp-server/issues/60))
- **School name search** spaces joined ampersands before querying College Scorecard. ([#62](https://github.com/cyanheads/college-scorecard-mcp-server/issues/62))
- **Program debt filters** use at-institution debt for graduate credentials and cumulative same-level debt for other credentials. Mixed-credential searches filter rows within each fetched school page and retain school continuation. ([#61](https://github.com/cyanheads/college-scorecard-mcp-server/issues/61))
- **Program inputs** report when CIP takes precedence over a nonblank program name. Resource page limits require positive decimal integers and clamp at 100. SDK validation for existing tool selector patterns remains tracked in [#65](https://github.com/cyanheads/college-scorecard-mcp-server/issues/65).
