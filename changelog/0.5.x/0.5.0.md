# 0.5.0 — 2026-11-03

## Added

- Add paged program resources and the college-scorecard-guide skill resource.
- **Program paging**: tools and custom program projections expose row limits, offsets, totals, and continuation; search drains program rows before advancing school pages. ([#28](https://github.com/cyanheads/college-scorecard-mcp-server/issues/28))
- **Completion earnings**: program outputs include separate one-/four-year medians, counts, availability, and dictionary provenance; one-year completion earnings drive filtering and ordering. Legacy highest-credential fields retain their population. ([#42](https://github.com/cyanheads/college-scorecard-mcp-server/issues/42))
- **CIP lookup**: cover all 464 current CIP 2020 four-digit groups, retain verified descendant aliases, and provide offset continuation. ([#46](https://github.com/cyanheads/college-scorecard-mcp-server/issues/46))
- **Comparison shortlists**: accept up to 1,000 raw IDs, compare the first five distinct normalized IDs, and report missing versus unprocessed IDs separately. ([#47](https://github.com/cyanheads/college-scorecard-mcp-server/issues/47))
- **Agent Plugins**: publish root plugin metadata and stdio connection configuration.

## Changed

- **Output formatting**: preserve literal upstream/caller text in Markdown and render school website values as links.
- **Packaging and maintenance**: sync framework skills and validation scripts, retain SDK skills runtime modules in portable bundles, ship the guide across install surfaces, and use a one-day dependency release-age guard.

## Fixed

- **Institution earnings provenance**: use the official 2022 data-file contexts and 2024 dollar basis for latest metrics, complete historical 2022 context, and add a maintenance dictionary check. ([#41](https://github.com/cyanheads/college-scorecard-mcp-server/issues/41))
- **OPEID6 pooling**: expose aggregation identity/scope and leave shared pooled comparison rows unranked; value analysis discloses pooled outcomes beside campus prices. ([#43](https://github.com/cyanheads/college-scorecard-mcp-server/issues/43))
- **Program-year prices**: retain tuition and attendance with independent price bases; mixed-period comparison rows stay unranked and unavailable prices carry no speculative explanation. ([#44](https://github.com/cyanheads/college-scorecard-mcp-server/issues/44))
- **Predominant degrees**: label 0 as “Not classified” and 4 as “Entirely graduate-degree granting.” ([#45](https://github.com/cyanheads/college-scorecard-mcp-server/issues/45))
- **Value analysis**: render the numeric debt-to-earnings ratio without uncited qualitative assessments. ([#48](https://github.com/cyanheads/college-scorecard-mcp-server/issues/48))
