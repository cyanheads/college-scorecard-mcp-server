# 0.2.0 — 2026-09-30

**Breaking:** program `enrollment` is gone from `scorecard_get_programs`, `scorecard_search_programs`, and `scorecard://programs/{id}`. Read `ipeds_awards_year1` and `ipeds_awards_year2` instead — IPEDS awards conferred in each of the two pooled debt-cohort years. They count awards, not enrollment or unique students, and no program-level enrollment figure replaces the old field.

## Added

- **`scorecard_search_schools` `sort`, `men_only`, `women_only`** ([#8](https://github.com/cyanheads/college-scorecard-mcp-server/issues/8)) — `sort` forwards an API sort expression such as `latest.cost.avg_net_price.overall:asc`. Each flag sends `1` for true and `0` for false; omitting it applies no filter and keeps schools with an unknown flag.
- **`scorecard_get_school` `men_only` / `women_only`** ([#8](https://github.com/cyanheads/college-scorecard-mcp-server/issues/8)) — booleans when the API reports the flag, absent when it does not; rendered as Yes/No.
- **`ipeds_awards_year1` / `ipeds_awards_year2`** ([#16](https://github.com/cyanheads/college-scorecard-mcp-server/issues/16)) on both program tools and the programs resource, read from `counts.ipeds_awards1` / `counts.ipeds_awards2`. Tools omit an unknown count; the resource returns `null`.

## Changed

- **Program `median_debt`** ([#16](https://github.com/cyanheads/college-scorecard-mcp-server/issues/16)) now reads `debt.staff_grad_plus.all.all_inst.median` — completers' median cumulative Stafford/Grad PLUS borrowing across institutions at the same academic level. `max_debt` filters on the same path, is inclusive, and now excludes programs with unknown debt.
- **`scorecard_get_programs` `earnings_count`** ([#16](https://github.com/cyanheads/college-scorecard-mcp-server/issues/16)) now reads `earnings.highest.1_yr.working_not_enrolled.overall_count`, the population behind the 1-year median.
- **`scorecard_search_programs` `min_earnings`** ([#18](https://github.com/cyanheads/college-scorecard-mcp-server/issues/18)) filters the fetched school page locally instead of being sent upstream, where the earnings field is not indexed. It is inclusive and now excludes programs with unavailable earnings; `total` and pagination stay school counts before local filtering.
- **`scorecard_list_fields` catalog** ([#8](https://github.com/cyanheads/college-scorecard-mcp-server/issues/8), [#16](https://github.com/cyanheads/college-scorecard-mcp-server/issues/16)) — `sortable` flags follow the data dictionary's INDEX column (`latest.earnings.6_yrs_after_entry.median` is no longer marked sortable), and the program entries use the paths above plus `credential.level`.
- **Docker image** — production dependencies and the OpenTelemetry peers (`scripts/install-otel.ts`) now install in a `$BUILDPLATFORM` stage, cross-installed for the target OS and CPU. Base images move to `oven/bun:1.4.2`; the image no longer sets `MCP_FORCE_CONSOLE_LOGGING`.
- **Packaging** — the npm `files` allowlist excludes `dist/*.mcpb`, and the `.mcpb` bundle leaves out `docs/idea.md` and `logs/`.
- **Framework scripts and skills** synced to `@cyanheads/mcp-ts-core` 0.13.10 — `lint-packaging` adds checks 13–15 (npm bundle exclusion, `manifest.json` version parity, Dockerfile build platform) and `release-github` gains `--check`. 31 skill directories and `CLAUDE.md` / `AGENTS.md` follow.
- **README and `docs/design.md`** describe the corrected program fields, school sorting, and page-local program ranking; embedded data counts are corrected to 202 CIP codes and 80 catalog fields.
- **Contract tests** ([#10](https://github.com/cyanheads/college-scorecard-mcp-server/issues/10)) — `tests/services/scorecard-contract.test.ts` drives the tools through the real `ScorecardService` over a fetch fake, including the empty-ID `ValidationError` that fails before any request.

## Removed

- **Program `enrollment`** ([#16](https://github.com/cyanheads/college-scorecard-mcp-server/issues/16)) from `scorecard_get_programs`, `scorecard_search_programs`, and `scorecard://programs/{id}` — see the migration note above.

## Fixed

- **`scorecard_value_analysis` `net_price_to_annual_earnings`** ([#20](https://github.com/cyanheads/college-scorecard-mcp-server/issues/20)) — the ratio divided `earnings_6yr_median`, already an annual figure, by six; it is now net price / `earnings_6yr_median`, so values are one sixth of what earlier versions returned. The description no longer claims a Carnegie peer-group comparison.
- **Full final pages no longer report `truncated: true`** ([#19](https://github.com/cyanheads/college-scorecard-mcp-server/issues/19)) — `scorecard_search_schools` and `scorecard_search_programs` derive continuation from the API's page metadata, so next-page guidance appears only when a later page exists.
- **`scorecard_search_programs` notices compose** ([#9](https://github.com/cyanheads/college-scorecard-mcp-server/issues/9)) — suppressed-earnings or no-match guidance and next-page guidance share one `notice` instead of the pagination text replacing the other.
- **A rejected API key fails after one attempt** ([#13](https://github.com/cyanheads/college-scorecard-mcp-server/issues/13)) — HTTP 401/403 and `API_KEY_MISSING` / `API_KEY_INVALID` responses carry `data.retryable: false`. HTTP 429 and 5xx responses still retry.
