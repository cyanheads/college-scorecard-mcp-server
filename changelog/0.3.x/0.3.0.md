# 0.3.0 — 2026-10-13

## Changed

- **Custom profile fields** now return real identity plus `selected_fields` and `absent_fields`. Migrate custom-mode reads from mapped properties to provider paths in `selected_fields`; nested program leaves retain the returned parent subtree, including sparse array positions and explicit nulls. ([#23](https://github.com/cyanheads/college-scorecard-mcp-server/issues/23))
- **Empty collections** succeed for existing schools without matching programs and offline catalog searches without matches, with recovery guidance instead of lookup errors. ([#36](https://github.com/cyanheads/college-scorecard-mcp-server/issues/36))
- **Provider failures** use distinct status-based codes and reasons with safe diagnostics, recovery, and request correlation. Permanent validation/authentication failures do not retry; deadlines cover response bodies and caller cancellation stops pending work. Resource HTTP 409 uses InvalidParams with `api_conflict`. ([#32](https://github.com/cyanheads/college-scorecard-mcp-server/issues/32), [#37](https://github.com/cyanheads/college-scorecard-mcp-server/issues/37))
- **Distribution maintenance** aligns npm registry launch metadata, adds hosted discovery, refreshes framework skills and checks, and moves Docker to Bun 1.4.2 → 1.4.3 with musl-only dependency pruning.

## Fixed

- **Required IDs and selectors** validate before fetch while retaining supported numeric string IDs, state lists, dotted CIP codes, ZIP-only searches, and decimal radii; optional blanks are unset and reversed ranges normalize. ([#22](https://github.com/cyanheads/college-scorecard-mcp-server/issues/22), [#32](https://github.com/cyanheads/college-scorecard-mcp-server/issues/32))
- **HBCU status** reads `school.minority_serving.historically_black` and preserves true, false, and unknown values. ([#29](https://github.com/cyanheads/college-scorecard-mcp-server/issues/29))
- **Batch profiles and catalogs** deduplicate IDs before the 100-ID serving cap, distinguish missing processed IDs from unchecked excess, and count catalog matches before slicing with accurate truncation and narrowing guidance. ([#33](https://github.com/cyanheads/college-scorecard-mcp-server/issues/33), [#31](https://github.com/cyanheads/college-scorecard-mcp-server/issues/31))
- **Search context** echoes effective normalized selectors and pagination defaults, with distinct notices for no upstream matches, exhausted pages, and locally filtered program pages. ([#36](https://github.com/cyanheads/college-scorecard-mcp-server/issues/36))
