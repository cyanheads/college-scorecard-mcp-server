# 0.1.8 — 2026-08-21

## Added

- **Community files** — `LICENSE`, `.gitattributes`, and `.github/SECURITY.md` / `CONTRIBUTING.md` / `CODE_OF_CONDUCT.md` scaffolded from the framework templates.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.10.8` → `^0.12.3`** — framework adoption onto the MCP SDK `^2.0.0` line. Tool, resource, and prompt surface unchanged.
- **Toolchain refresh** — TypeScript `^6.0.3` → `^7.0.2`, Biome `^2.5.9`, Vitest `^4.1.11`, Bun pinned to 1.4 (`packageManager`, `oven/bun:1.4.0` images). `tsconfig.json` now typechecks `tests/` with `noEmit`; `tsconfig.build.json` emits from `src/` only.
- **Docker image** — build stage pinned to `--platform=$BUILDPLATFORM` so the amd64 leg of a multi-arch build doesn't run Bun under QEMU (MemoryExhaustion on arm64 hosts); BuildKit cache mounts and `--omit=peer` production installs slim the runtime layer.
- **Supply-chain guard** — `bunfig.toml` blocks packages published less than 3 days ago (`minimumReleaseAge`, framework excluded) and installs through the Socket security scanner.
- **Re-synced skills, scripts, and docs** — project skills, devcheck/lint/packaging scripts, `changelog/template.md`, and CLAUDE.md regenerated from the `^0.12.3` templates; new `scripts/check-dependency-specifiers.ts`.
- **Descriptions aligned** — `manifest.json` and both plugin manifests now carry the package.json description ("… via MCP. STDIO or Streamable HTTP.").

## Fixed

- **Enrichment truncation fields** — `scorecard_search_schools`, `scorecard_search_programs`, `scorecard_list_fields`, and `scorecard_lookup_cip` always emit `truncated`/`shown`/`cap`; results under the page cap previously omitted them and failed output validation with error -32007.
- **`resources/list` discovery** — `scorecard://school/{id}` and `scorecard://programs/{id}` gained `list` callbacks advertising representative example schools; `resources/list` previously returned neither resource.
- **Empty ID lists** — fetching schools by IDs throws `validationError` instead of `notFound` when the list is empty.
- **Fresh-clone build** — `src/data/cip-codes.ts` and `src/data/field-catalog.ts` are tracked again; the unanchored `data/` gitignore pattern was excluding `src/data/`, leaving fresh clones without imported modules.
